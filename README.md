Hey, I'm Arash 👋 a backend engineer who likes building things that have to keep working: payments, APIs, infrastructure, and lately a lot of AI agents.

- 🎮 Most recently I led the backend of a live gaming platform with real money flowing through it: payments, a creator marketplace, a game launcher, and the tests and monitoring that kept it all running.
- 🤖 I've been building AI features in production: sandboxed agents with MCP tools, real-time voice, and memory for long conversations.
- 🌐 Before that I ran my own fleet of Linux servers and wrote networking tools in Go, which is where sluice came from.
- 🔬 On the side I tinker with machine learning: hypergraphs, reinforcement learning and a bit of computer vision.

💬 Curious about my work? Ask my AI at [ask.devarash.icu](https://ask.devarash.icu). It answers from my own notes and shows where each answer came from.
